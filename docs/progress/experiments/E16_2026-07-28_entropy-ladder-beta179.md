# E16 — 熱熵 ladder 再延伸 β=81.75→178.74,warm-start(2026-07-28)

## 目的
E15 之後把 S/N 平台再往低溫推一倍(T 到 0.0056),第一次實戰驗證
final_config warm-start 續積工作流。

## 設定
- 同 E15;5 rungs β = 95.60/111.79/130.72/152.86/178.74(續同公比 r=1.16934),
  每 rung 128 萬樣本,seed=44;job 27054,24.7 h(~1580 CPU-h)
- **Warm-start**:`CONFIG_IN=...prod_ext80`(β=81.75 存檔組態+RNG),第一
  rung 只做 1000 sweeps 再平衡 — 無 E15 的冷啟動偏差,無需 overlap rung
- 資料 `data/sse_entropy_6x6_delta4.5_prod_ext160/`(+configs @β=178.74)

- ⚠️ 成本刻度:s/β 隨 M 成長(op string 出 cache、64 rank 頻寬競爭)從
  85(β=82)爬到 ~130(β=110+),別再用 70 s/β 外插大 β

## 結果
- E/N 全程平台:5 rungs 皆在 −0.9639…−0.9732(±1σ 擺動),無下沉
- 三目錄合併(丟 ext80 β=20,E15 慣例)低溫端 S/N:
  0.110(12) @β=81.75 → 0.114(13) @95.6 → 0.088(14) @111.8 →
  0.096(17) @130.7 → 0.103(17) @152.9 → **0.112(19) @178.74**
- rung-decimation(半密度)@β=178.7:0.100 vs 0.112,差 −0.012 ≈ 0.6σ →
  quadrature 系統誤差 ≲ 統計誤差,無法解析、也不主導
- 誤差由 β·SEM(E) 端點項主導(0.019 @β=178.7),隨 β 線性放大

## 結論
**S/N 平台從 T=0.05 一路撐到 T≈0.0056(β=178.7)不動**,終點 0.112(19) ≈
ln2/6 = 0.1155 — δ=4.5 的 RCSL 熵平台再推低一倍,累計比 E13 原始資料低 9 倍
溫度,仍無熵釋放/有序化跡象。warm-start 續積工作流驗證成功(接縫無偏差)。
